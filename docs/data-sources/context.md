# circleci_context (Data Source)

Fetches information about a CircleCI context, including its restrictions. Look the context up either by `id`, or by `name` within the organization given by `organization_id`.

## Example Usage

Look up a context by its ID:

```terraform
data "circleci_context" "example" {
  id = "00000000-0000-0000-0000-000000000000"
}
```

Look up a context by its name. Context names are unique within an organization, so `organization_id` is required:

```terraform
data "circleci_context" "example" {
  organization_id = "00000000-0000-0000-0000-000000000000"
  name            = "production"
}
```

## Schema

### Optional

- `id` (String) The ID of the context. Exactly one of `id` or `name` must be set.
- `name` (String) The name of the context. Exactly one of `id` or `name` must be set. Looking a context up by `name` requires `organization_id`.
- `organization_id` (String) The ID of the organization that owns the context, used to look the context up by `name`. Context names are unique within an organization. Cannot be set together with `id`.

### Read-Only

- `created_at` (String) The timestamp when the context was created.
- `restrictions` (Attributes List) The access restrictions for this context. (see [below for nested schema](#nestedatt--restrictions))
