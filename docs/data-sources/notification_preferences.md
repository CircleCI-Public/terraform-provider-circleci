# circleci_notification_preferences (Data Source)

Lists the notification preferences of a CircleCI project, in the order CircleCI displays them, so that their IDs can be looked up by name for `circleci_project_notification_preferences`.

## Example Usage

```terraform
data "circleci_notification_preferences" "example" {
  organization_id = "00000000-0000-0000-0000-000000000000"
  project_id      = "11111111-1111-1111-1111-111111111111"
}

output "notification_preferences" {
  value = {
    for p in data.circleci_notification_preferences.example.preferences :
    "${p.section_name}/${p.group_name}/${p.name}" => p.id
    if p.is_user_configurable
  }
}
```

### Required

- `preferences` (Attributes List) The project's notification preferences. (see [below for nested schema](#nestedatt--preferences))

<a id="nestedatt--preferences"></a>
### Nested Schema for `preferences`

Read-Only:

- `channel` (String) The channel the preference applies to, such as `slack`.
- `group_name` (String) The group the preference is shown under, such as `Workflow Completed`.
- `id` (String) The ID of the preference. It is the same for every project.
- `is_enabled` (Boolean) Whether the preference is on for the project.
- `is_user_configurable` (Boolean) Whether the preference can be turned on or off. Only these can be used in `circleci_project_notification_preferences`.
- `name` (String) The name of the preference, such as `Job awaiting approval`.
- `section_name` (String) The section the preference is shown under, such as `Build`.
