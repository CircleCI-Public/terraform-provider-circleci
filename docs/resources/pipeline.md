# circleci_pipeline (Resource)

Manages a CircleCI pipeline definition. A pipeline definition specifies where to find the pipeline configuration and where to check out code from. CircleCI resolves a `forgejo` repository through the organization's Forgejo connection when the pipeline is created, so make the pipeline depend on the `circleci_forgejo_connection` resource; destroying that connection also deletes its Forgejo pipelines.

## Example Usage

### GitHub App Pipeline

```terraform
resource "circleci_pipeline" "example" {
  project_id                       = "00000000-0000-0000-0000-000000000000"
  name                             = "my-pipeline"
  description                      = "My pipeline description"
  config_source_provider           = "github_app"
  config_source_file_path          = ".circleci/config.yml"
  config_source_repo_external_id   = "123456789"
  checkout_source_provider         = "github_app"
  checkout_source_repo_external_id = "123456789"
}
```

### Forgejo Pipeline

A Forgejo repository can be identified by its full name; CircleCI fills in its ID. See the [Forgejo guide](../guides/forgejo.md).

```terraform
resource "circleci_pipeline" "forgejo" {
  project_id                     = circleci_project.example.id
  name                           = "build"
  description                    = "Builds the service"
  config_source_provider         = "forgejo"
  config_source_repo_full_name   = "example-org/service"
  config_source_file_path        = ".circleci/config.yml"
  checkout_source_provider       = "forgejo"
  checkout_source_repo_full_name = "example-org/service"

  depends_on = [circleci_forgejo_connection.example]
}
```

## Schema

### Required

- `checkout_source_provider` (String) The VCS provider for the pipeline's checkout source. Must be one of `github_app`, `github_server` or `forgejo`. Changing this value to or from `forgejo` forces a new resource.
- `config_source_file_path` (String) The path to the pipeline configuration file within the repository.
- `config_source_provider` (String) The VCS provider for the pipeline's configuration source. Must be one of `github_app`, `github_server` or `forgejo`. A `forgejo` pipeline needs the organization's `circleci_forgejo_connection`, and its config and checkout sources must both be `forgejo`. Changing this value to or from `forgejo` forces a new resource.
- `description` (String) A description of the pipeline.
- `name` (String) The name of the pipeline. Changing this value forces a new resource to be created.
- `project_id` (String) The ID of the project this pipeline belongs to.

### Optional

- `checkout_source_repo_external_id` (String) The external ID of the repository to check out code from. Required for `github_app` and `github_server`. For `forgejo` it is the Forgejo repository ID, and either it or `checkout_source_repo_full_name` must be set; changing it forces a new resource.
- `checkout_source_repo_full_name` (String) The full name of the repository used for code checkout. Can only be set for `forgejo`, where it identifies the repository when `checkout_source_repo_external_id` is not set; changing it forces a new resource.
- `config_source_repo_external_id` (String) The external ID of the repository containing the pipeline configuration. Required for `github_app` and `github_server`. For `forgejo` it is the Forgejo repository ID, and either it or `config_source_repo_full_name` must be set; changing it forces a new resource.
- `config_source_repo_full_name` (String) The full name of the repository containing the pipeline configuration. Can only be set for `forgejo`, where it identifies the repository when `config_source_repo_external_id` is not set; changing it forces a new resource.

### Read-Only

- `created_at` (String) The timestamp when the pipeline was created.
- `id` (String) The unique identifier of the pipeline.
