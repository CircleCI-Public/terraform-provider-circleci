# circleci_project_notification_preferences (Resource)

Sets which notifications a CircleCI project sends to its Slack channel, as configured under Project Settings > Slack Notifications. Use at most one per project.

This resource is authoritative: every user-configurable preference that is not in `enabled_preference_ids` is turned off, including ones turned on outside Terraform. Destroying it turns every user-configurable preference off. Look preference IDs up with the `circleci_notification_preferences` data source.

~> **Note:** This resource is authoritative for the project. Declare at most one per project: two would turn each other's preferences off.

~> **Note:** Destroying this resource turns every user-configurable preference of the project off. It does not restore CircleCI's defaults.

## Example Usage

```terraform
locals {
  organization_id = "00000000-0000-0000-0000-000000000000"
  project_id      = "11111111-1111-1111-1111-111111111111"
}

data "circleci_notification_preferences" "example" {
  organization_id = local.organization_id
  project_id      = local.project_id
}

locals {
  # Look preferences up by section, group and name instead of hard-coding IDs.
  wanted = toset([
    "Build/Workflow Completed/On default branch (failed, error, unauthorized)",
    "Build/Job/Job awaiting approval",
    "Deployments/Releases/Failed",
  ])
}

# Every user-configurable preference not listed here is turned off.
resource "circleci_project_notification_preferences" "example" {
  organization_id = local.organization_id
  project_id      = local.project_id

  enabled_preference_ids = [
    for p in data.circleci_notification_preferences.example.preferences : p.id
    if contains(local.wanted, "${p.section_name}/${p.group_name}/${p.name}")
  ]
}
```

## Schema

### Required

- `enabled_preference_ids` (Set of String) The IDs of the preferences to turn on. Every other user-configurable preference is turned off.
- `organization_id` (String) The ID of the organization that owns the project. Changing this value forces a new resource.
- `project_id` (String) The ID of the project. Changing this value forces a new resource.

### Read-Only

- `id` (String) `<organization_id>/<project_id>`.

## Import

Import is supported using `organization_id/project_id`:
