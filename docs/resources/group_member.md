# circleci_group_member (Resource)

Adds a user to a CircleCI group. Each resource manages one membership, so members added outside Terraform are left alone. The user must already be a member of the organization; CircleCI has no API to invite users or to look them up by name, so `user_id` is the user's CircleCI ID.

## Example Usage

```terraform
resource "circleci_group_member" "alice" {
  organization_id = circleci_group.platform.organization_id
  group_id        = circleci_group.platform.id
  user_id         = "00000000-0000-0000-0000-000000000001"
}
```

## Schema

### Required

- `group_id` (String) The ID of the group. Changing this value forces a new resource.
- `organization_id` (String) The ID of the organization that owns the group. Changing this value forces a new resource.
- `user_id` (String) The CircleCI ID of the user. Changing this value forces a new resource.

### Read-Only

- `id` (String) The ID of the membership, of the form `group_id/user_id`.
- `username` (String) The user's username, when CircleCI reports it.
