# circleci_project_slack_notification (Resource)

Sends a CircleCI project's notifications to a Slack channel, as configured under Project Settings > Slack Notifications. A project has at most one Slack channel. Choose which notifications are sent with `circleci_project_notification_preferences`.

The organization must have the CircleCI Slack App installed. CircleCI posts a "Welcome! CircleCI is now configured to post updates" message into the channel when this resource is created, and whenever it is updated while enabled.

~> **Note:** `channel` must be the Slack channel ID (for example `C0123456789`), not the channel name. CircleCI reports the channel by ID, so a name would show as a change on every plan.

~> **Note:** Because of the welcome message, the provider only sends an update when `channel` or `enabled` changes. Re-applying an unchanged configuration posts nothing.

If the configuration is deleted outside Terraform, the next plan creates it again.

## Example Usage

```terraform
# The organization must have the CircleCI Slack App installed. CircleCI posts a
# welcome message into the channel on create, and on every update while enabled.
resource "circleci_project_slack_notification" "example" {
  organization_id = "00000000-0000-0000-0000-000000000000"
  project_id      = "11111111-1111-1111-1111-111111111111"

  # The Slack channel ID, not its name.
  channel = "C0123456789"
  enabled = true
}
```

## Schema

### Required

- `channel` (String) The ID of the Slack channel, such as `C0123456789`, not its name. In Slack, it is at the bottom of the channel details.
- `organization_id` (String) The ID of the organization that owns the project. Changing this value forces a new resource.
- `project_id` (String) The ID of the project. Changing this value forces a new resource.

### Optional

- `enabled` (Boolean) Whether notifications are posted to the channel. Defaults to `true`.

### Read-Only

- `channel_name` (String) The name of the Slack channel, when CircleCI reports it.
- `disable_reason` (String) Why CircleCI disabled the channel, when it did.
- `id` (String) The ID of the channel configuration.

## Import

A project has at most one Slack channel, so import is supported using `organization_id/project_id`:

```shell
terraform import circleci_project_slack_notification.example "<organization_id>/<project_id>"
```
