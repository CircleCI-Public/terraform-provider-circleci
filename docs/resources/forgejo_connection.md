# circleci_forgejo_connection (Resource)

Connects a CircleCI organization to a Forgejo instance, so the organization's pipelines can check out code from and be triggered by Forgejo repositories. An organization can have only one Forgejo connection.

CircleCI checks the instance before it stores the connection, so the following must already exist in Forgejo (version 16 or later): a user without site administrator rights that can see `owner`, and two Authorized Integrations created by that user. Both integrations trust the issuer `https://oidc.circleci.com/org/<organization_id>`, and each has a claim rule requiring `sub` to equal its subject: `circleci/soc-integrations/forgejo/connection` for the connection integration (scopes `read:user`, `read:organization` and `read:repository`, since CircleCI also uses it to look up repositories and fetch configuration), and `circleci/soc-integrations/forgejo/checkout` for the checkout integration (scope `read:repository`).

After creating the connection, create a webhook in Forgejo for `owner` that sends `webhook_events` to `webhook_url`, signed with `webhook_secret`.

Destroying the connection also deletes every pipeline and trigger CircleCI holds for its repositories. It changes nothing in Forgejo, so delete the webhook and both Authorized Integrations there yourself.

## Example Usage

```terraform
resource "circleci_organization" "example" {
  name     = "example"
  vcs_type = "circleci"
}

resource "circleci_forgejo_connection" "example" {
  organization_id     = circleci_organization.example.id
  url                 = "https://forgejo.example.com"
  owner               = "example-org"
  connection_audience = var.forgejo_connection_audience
  checkout_audience   = var.forgejo_checkout_audience

  # Optional, for example to authenticate to a proxy in front of Forgejo.
  request_headers = {
    "X-Proxy-Token" = var.forgejo_proxy_token
  }
}

output "forgejo_webhook_url" {
  value = circleci_forgejo_connection.example.webhook_url
}

output "forgejo_webhook_secret" {
  value     = circleci_forgejo_connection.example.webhook_secret
  sensitive = true
}
```

## Schema

### Required

- `checkout_audience` (String) The audience Forgejo generated for the checkout Authorized Integration, copied from the integration's settings.
- `connection_audience` (String) The audience Forgejo generated for the connection Authorized Integration, copied from the integration's settings.
- `organization_id` (String) The ID of the CircleCI organization to connect. Changing this value forces a new resource, which deletes the organization's Forgejo pipelines and triggers.
- `owner` (String) The Forgejo organization, or user, whose repositories CircleCI builds. A user owner must be the user that created the Authorized Integrations. Changing this value forces a new resource, which deletes the organization's Forgejo pipelines and triggers. CircleCI does not report it, so after an import it is taken from the configuration.
- `url` (String) The base URL of the Forgejo instance, which must be reachable from CircleCI. Changing this value forces a new resource, which deletes the organization's Forgejo pipelines and triggers. CircleCI reports it only in a canonical form, which can differ from the configured value, so after an import it is taken from the configuration.

### Optional

- `request_headers` (Map of String, Sensitive) Headers CircleCI sends with every request to the Forgejo instance, for example to authenticate to a proxy in front of it. CircleCI never returns header values, so only added or removed headers are detected as drift.
- `webhook_secret_rotation` (String) Any value. Setting it to a new value issues a new `webhook_secret`; update the Forgejo webhook with it. Removing it does not. The previous secret keeps verifying deliveries until one signed with the new secret arrives.

### Read-Only

- `id` (String) The ID of the connection.
- `owner_id` (String) The Forgejo ID of `owner`.
- `owner_type` (String) Whether `owner` is a Forgejo `organization` or `user`.
- `webhook_events` (List of String) The events the Forgejo webhook must send. Not set after an import.
- `webhook_secret` (String, Sensitive) The secret the Forgejo webhook signs deliveries with. CircleCI returns it only when the connection is created and when the secret is rotated, so it is not set after an import until `webhook_secret_rotation` is changed.
- `webhook_url` (String) The URL of the webhook to create in Forgejo. Not set after an import.

## Import

Import is supported using `organization_id/connection_id`:

```shell
terraform import circleci_forgejo_connection.example "<organization_id>/<connection_id>"
```
