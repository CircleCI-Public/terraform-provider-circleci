# circleci_group_project_role (Resource)

Grants a CircleCI group a role on a project. Only standalone (`circleci`) organizations support reading the grant back.

## Example Usage

```terraform
resource "circleci_group_project_role" "platform_service" {
  organization_id = circleci_group.platform.organization_id
  group_id        = circleci_group.platform.id
  project_id      = circleci_project.service.id
  role            = "project-contributor"
}
```

## Schema

### Required

- `group_id` (String) The ID of the group. Changing this value forces a new resource.
- `organization_id` (String) The ID of the organization that owns the group and the project. Changing this value forces a new resource.
- `project_id` (String) The ID of the project. Changing this value forces a new resource.
- `role` (String) The role to grant. Must be one of `project-admin`, `project-contributor` or `project-viewer`. Changing this value forces a new resource, so the group briefly holds no role on the project.

### Read-Only

- `id` (String) The ID of the grant, of the form `group_id/project_id`.

## Import

Import is supported using `organization_id/group_id/project_id`:

```shell
terraform import circleci_group_project_role.example "<organization_id>/<group_id>/<project_id>"
```
